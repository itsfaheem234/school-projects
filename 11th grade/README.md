# quiz-application-with-timer-and-analysis
a *python-based* quiz application with a graphical interface, timer, randomised questions, scoring, and grade evaluation. the application is designed to test knowledge of class 11 *python* concepts.

## features

1)GUI built with Tkinter

2)10 randomly selected multiple-choice questions

3)5-minute countdown timer

4)Automatic score and percentage calculation

5)Grade-based performance evaluation

6)Retry option

7)Input validation

## tech stack

1) *python*
2) *tkinter*
3) ```random```
4) ```tkinter.ttk```
5) ```tkinter.messagebox```

## requirements

1) python 3.7 or higher
2) tkinter

## installation

1) clone or download this repository.
2) make sure *python* 3.7+ is installed.
3) run the *python* file.

## usage

start the application and follow the instructions on screen. select an answer for each question and click next. the quiz ends after all 10 questions are answered or when the timer reaches zero.
